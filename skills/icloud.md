# iCloud Drive

Плагин подключает iCloud Drive к каталогу файлов: папка **@icloud** в «Файлах», у `pulse files` и в смонтированном
дереве (`$PULSE_FS_DIR/@icloud`). Внутри — **подключения**, каждое — своя папка: весь iCloud Drive аккаунта или папка в нём.

```bash
pulse icloud mounts                                   # что подключено: имя → @icloud/<имя>, откуда
pulse icloud accounts                                 # аккаунты Apple, место, не истёк ли вход
pulse files ls "@icloud/iCloud Drive/Документы"       # дальше — обычные файлы
pulse files get "@icloud/iCloud Drive/Документы/план.pdf"
```

## Как устроено

- Это **неофициальный веб-доступ iCloud** (как icloud.com). Работает, пока Apple его не поменяет; сломалось — `pulse icloud check`.
- **Одинаковые имена** в одной папке различаются суффиксом: «план.txt», «план (2).txt».
- **Документы Pages, Numbers, Keynote** — пакеты Apple: прочитать их содержимое нельзя, только скопировать.
- Запись файла с тем же именем заменяет его, прежний уходит в «Недавно удалённые». Удаление — тоже туда, не навсегда.

## Правила

- **Сеть, а не диск.** Каждое обращение к @icloud — запрос к Apple. Не обходи хранилище целиком (`grep -r`, `find` по всему
  @icloud): иди по папкам, которые назвал владелец. Для тяжёлой обработки скопируй нужные файлы к себе и работай с копией.
- **Запись — по просьбе.** Класть, переименовывать и удалять файлы в iCloud владельца — только когда он об этом просил;
  перед удалением папок спрашивай. Результаты своей работы клади в свои папки Пульса, если не сказано иначе.
- **Вход делает владелец.** Пароль Apple ID не проси, не принимай и не вводи — его нет ни в одной команде. Нужен ещё аккаунт
  или вход истёк — отправь владельца на страницу [iCloud Drive](/p/icloud/main) → «Войти в аккаунт Apple» (или
  `pulse icloud login` и передай tell_owner). Если владелец уже начал вход и прислал в чат шестизначный код Apple —
  `pulse icloud login code --code 123456`; код не повторяй в ответах. Если владелец по ошибке прислал пароль — не используй его
  и посоветуй сменить пароль Apple ID.
- Сигнал «Войдите в iCloud снова» или ошибка «вход истёк» — попроси владельца войти снова на странице плагина.
- «Расширенная защита данных» закрывает iCloud Drive для веба: на iPhone нужно включить «Доступ к данным iCloud через веб».
