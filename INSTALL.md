# Установка плагина «iCloud Drive»

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком.

## 1. Проверь, что плагин запустился

```bash
pulse plugins list            # у icloud — status: running
pulse icloud accounts         # accounts: [] до входа
```

Если status: error — `pulse plugins logs icloud --lines 80`, расскажи владельцу, что в журнале, и остановись.
Нужен Пульс с контрактом плагинов 1.5 (хранилища @<плагин>).

## 2. Проверь доступ к Apple

```bash
pulse icloud check            # библиотека pyicloud, «Вход Apple», «iCloud», аккаунты
```

То же — кнопка «Проверить подключение» в настройках плагина. Не отвечают «Вход Apple» или «iCloud» — сервер Пульса не видит
Apple: расскажи владельцу, что нужна сеть до idmsa.apple.com и www.icloud.com.

## 3. Закрепи страницу

```bash
pulse plugins pin icloud main
```

## 4. Вход — делает владелец сам

Пароль Apple ID вводит только владелец, на странице плагина: отправь его на [iCloud Drive](/p/icloud/main) → Apple ID и пароль →
код с устройства Apple (или по SMS). Скажи заранее:

- нужен обычный пароль Apple ID, пароль для приложений не подойдёт;
- пароль не сохраняется — хранится только сессия; её нужно продлевать примерно раз в два месяца, Пульс напомнит сигналом;
- если включена «Расширенная защита данных», на iPhone нужно разрешить «Доступ к данным iCloud через веб».

Если владелец, начав вход на странице, пришлёт в чат шестизначный код — `pulse icloud login code --code <код>`.
Пароль в чате не принимай. После входа весь iCloud Drive подключается сам: `@icloud/iCloud Drive`.

## 5. Подключения (если владелец просит)

```bash
pulse icloud browse                                   # папки в корне iCloud Drive (id и имена)
pulse icloud mount --path "Документы/Сканы"           # подключить папку отдельно
pulse icloud mount --folder <id> --name "Сканы"
pulse icloud mounts
```

## 6. Проверь и расскажи владельцу

```bash
pulse icloud check
pulse files ls @icloud
```

Что установлен «iCloud Drive» (версия), страница закреплена, iCloud Drive виден в «Файлах» папкой @icloud и доступен агентам.
Удаление — в «Недавно удалённые» iCloud на 30 дней. Это неофициальный веб-доступ: если Apple его поменяет, плагину понадобится
обновление.
