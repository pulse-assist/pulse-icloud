# iCloud Drive для «Пульса»

Плагин подключает iCloud Drive к «Пульсу»: папка **@icloud** в «Файлах», у `pulse files` и в смонтированном дереве агентов.

- **Несколько аккаунтов Apple.** Вход на странице плагина: Apple ID и пароль, затем код с устройства Apple или по SMS.
  Пароль уходит только в Apple и **не сохраняется** — хранится доверенная сессия (`sessions/<аккаунт>` в данных плагина);
  Apple отзывает её примерно через два месяца, тогда Пульс получает сигнал «Войдите в iCloud снова».
- **Подключения** — папки в @icloud: весь iCloud Drive (подключается сам при входе) или папка в нём.
- **Файлы** читаются и пишутся как обычные. Запись поверх файла заменяет его (прежний — в «Недавно удалённые»), удаление —
  тоже туда, на 30 дней. Документы Pages, Numbers, Keynote видны как есть.
- **Команды агентов:** `pulse icloud accounts | login | login code | login status | logout | browse | mounts | mount | rename |
  unmount | check` — см. `commands.json`. Пароля нет ни в одной команде: вход делает владелец.

Файлы не копируются на сервер Пульса: каждая операция — запрос к iCloud.

## Почему неофициальный доступ

У Apple нет открытого API для iCloud Drive (CloudKit не открывает файлы пользователя сторонним приложениям). Плагин работает
так же, как icloud.com, через библиотеку [pyicloud](https://pypi.org/project/pyicloud/) (версия закреплена в
`backend/requirements.txt`). Если Apple поменяет веб-доступ, вход или файлы перестанут открываться до обновления библиотеки;
`pulse icloud check` покажет, где обрыв.

Ограничения:
- аккаунт с ключом безопасности (FIDO) вместо кода не поддерживается;
- с «Расширенной защитой данных» нужно разрешить на iPhone «Доступ к данным iCloud через веб»;
- аккаунты материкового Китая (icloud.com.cn) не проверялись.

## Права

`files:provide` — хранилище @icloud; `signals:create` — сигнал об истёкшем входе; `network` — запросы к Apple.

## Разработка

```bash
pip install -r backend/requirements-dev.txt
pulse-plugin check
cd backend && python -m pytest          # iCloud подменён (tests/fake_apple.py), сеть не нужна
```

Код Apple — только в `backend/icloud_plugin/apple.py`; остальное его подменяет в тестах. Нужен Пульс с контрактом плагинов 1.5.
